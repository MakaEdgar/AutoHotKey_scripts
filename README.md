# AutoHotkey scripts

Small AutoHotkey v1 scripts and `.reg` helpers for Windows.

This repo contains small utilities for input and keyboard behavior: layout switching, diacritics, device-specific remaps, Total Commander / ConEmu helpers, and Num Lock registry tweaks.

## Layout switching

CapsLock-based layout switching and alternative layout hotkeys.

- `layout_change_capslock_multilang.ahk`
- `layout_change_capslock_2_shift_alt.ahk`
- `layout_change_capslock_2_shift_ctrl.ahk`

## Diacritics

Hotkeys for Dutch and French diacritics on QWERTY and AZERTY layouts.

- `diacritics_dutch_4_querty.ahk`
- `diacritics_french_4_querty.ahk`
- `diacritics_french_4_azerty_extended.ahk`

## Keyboard remaps

Custom remaps for specific keyboards, remote-style control, and Parsec/Android usage.

- `kb_sculpt.ahk`
- `kb_qtron_android_parsec.ahk`
- `tv_clicker.ahk`

## Total Commander / ConEmu

Quick switching between Total Commander and ConEmu with different hotkeys.

- `tcmd_conemu_space_alt.ahk`
- `tcmd_conemu_space_ctrl.ahk`

## Registry

Registry helpers to disable or restore the Num Lock key behavior.

- `numlock_disable.reg`
- `numlock_enable.reg`
